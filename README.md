# Study Window

A static study-session planner built with HTML, CSS, and JavaScript.

## Run locally

Open index.html in a browser. The plan is saved in that browser using local storage.

## Publish with GitHub Pages

1. Create a GitHub repository and upload index.html, the assets folder, and this README to the repository root.
2. Open the repository Settings and select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the main branch and the root folder, then save.
5. When GitHub Pages finishes publishing, open the URL shown on the Pages settings screen.

The Pages URL may take a few minutes to become available after the first deployment.
